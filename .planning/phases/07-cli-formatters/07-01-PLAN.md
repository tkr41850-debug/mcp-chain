**LD-1 — Exit code contract (from CONTEXT.md §Exit code contract; bash monitor + Phase 8 slash-commands depend on these):**

**LD-2 — Testability pattern (mirror Phase 6 LD-2 verbatim):** Each command gets a `run<Cmd>(out, errW io.Writer, path string, ...) int` pure function plus a `<Cmd>Cmd.Run` shell that resolves the state path and invokes the run function, calling `os.Exit(code)` only on non-zero. Unit tests call the `Run<Cmd>` alias (re-exported from `export_test.go`) with `bytes.Buffer` pairs.

**LD-3 — `runList` / `runPurge` / `runResolve` MUST NOT call `statepath.Resolve()`** (pitfall 3 / Phase 6 LD-3 carryover). The state-path resolve lives in `<Cmd>Cmd.Run`; unit tests pass `t.TempDir()+"/state.json"` and never touch `$XDG_STATE_HOME`/`$HOME`.

**LD-4 — Do NOT implement `ExitCoder` for any error branch.** Same reason as Phase 6 LD-4: returning a kong `ExitCoder` error causes `FatalIfErrorf` to write the error message to stderr before exiting, polluting the empty-stderr contract rows. Always return an int from `runXxx` and `os.Exit` from `Run`.

**LD-5 — `list` empty-store hint goes to STDERR, exit 0 (NOT stdout, NOT exit 1).** Matches POSIX spirit (`ls` on empty dir). Downstream pipes like `mcp-chain list | grep <id>` must not receive the hint as fake data. See 07-CONTEXT.md §List formatting and 07-RESEARCH.md pitfall 6.

**LD-6 — `purge` uses store-side validation for the tri-state arg shape.** The kong `xor:"target"` tag enforces only "`--all` and `--resolved` mutually exclusive". Bare `purge` (no args, no flags) parses successfully at the kong layer, flows into `runPurge` with all zero values, and reaches `store.Purge({})` which returns `ErrPurgeArgRequired`. The CLI translates this sentinel to the locked stderr line (pitfall 5; research §Pattern 3). Do NOT add a custom `AfterApply` kong hook — that duplicates the store validator.

**LD-7 — `resolve` without `--force` ALWAYS fails on Phase 5 records.** The CLI has no MCP session and thus no OwnerToken; `runResolve` passes `""` to `store.Resolve`, which does `subtle.ConstantTimeCompare([]byte(""), []byte(r.OwnerToken))` and returns `ErrNotOwner` (records registered via MCP carry a non-empty 32-char hex token — Phase 5). The CLI surfaces the `--force` hint in that branch. This is by design, not a bug (pitfall 4 / 07-CONTEXT.md §Resolve semantics).

**LD-8 — `list` sort order: `CreatedAt` ASC, ties broken by `ID` ASC, stable.** Locked by 07-CONTEXT.md §List formatting. `store.List()` returns records in UNSPECIFIED order (map iteration — pitfall 2). The sort lives in `format.WriteTable`, NOT in `runList`, so presentation rules stay localized.

**LD-9 — `list` CONDITION truncation: 48 chars with `"..."` suffix.** Locked by 07-CONTEXT.md §List formatting. Guard against short strings with an early-return `if len(s) <= max { return s }` (pitfall 7 — `s[:max-3]+"..."` without the guard panics on strings < 45 chars).

**LD-10 — `list` timestamps: RFC3339 UTC with `-` for nil `ResolvedAt`.** `t.UTC().Format("2006-01-02T15:04:05Z07:00")`. Empty `ResolvedAt` → literal `-` (single char; tabwriter right-pads to column width). Locked by 07-CONTEXT.md.

**LD-11 — `format.WriteTable` is pure.** No store access, no env reads, no `os.Stdout` fallback. Takes `io.Writer` + `[]store.Record` + returns `error`. Empty input → no output (caller owns the empty-store hint). Lives in `internal/cli/format` sub-package so rendering never leaks into `internal/store` (hexagonal boundary — 07-CONTEXT.md §Package layout).

**LD-12 — Counter is NEVER decremented by purge.** This is a Phase 4 property (store.go:188 comment). Phase 7 adds `TestPurge_CounterNotDecremented` as a regression guard: register 3 → `purge --all` → read state.json raw → assert `Counter == 3`. Counter is NOT on `store.Record` (pitfall 3 — must read the raw JSON via `json.Unmarshal` into a partial struct).

**LD-13 — `ResolveCmd` is a greenfield type, not a stub migration.** Current `internal/cli/stubs.go` declares `ListCmd` and `PurgeCmd` only — NO `ResolveCmd` exists at HEAD, and the current `cmd/mcp-chain/main.go` CLI struct has NO `Resolve` field. Task 4 introduces both the type and the grammar wiring atomically.

**LD-14 — No new flags in v1 beyond `--force`.** No `--format`, no `--status=pending`, no `--watch`, no `resolve --all`, no interactive `purge --all` prompt. All explicitly deferred in 07-CONTEXT.md §Deferred Ideas.

    // Package format renders store.Record slices into operator-friendly
    // output. Currently supports WriteTable (aligned 5-column ASCII table
    // via stdlib text/tabwriter). Lives in its own sub-package so
    // presentation concerns never leak into internal/store.
    //
    // WriteTable is PURE: no store access, no env-var reads, no os.Stdout
    // fallback. Empty input yields zero output (caller owns the
    // "no entries" hint). See LD-11 in 07-01-PLAN.md.
    package format

    import (
        "fmt"
        "io"
        "sort"
        "text/tabwriter"
        "time"

        "github.com/anthropics/mcp-chain/internal/store"
    )

    // conditionMaxWidth caps the CONDITION column so a pathological
    // multi-line condition can't wreck alignment. 48 is the CONTEXT.md
    // lock (LD-9). ASCII assumption is fine for a cap this generous.
    const conditionMaxWidth = 48

    // tsFormat is RFC3339 in UTC (LD-10). Fixed-width (20 chars w/ 'Z' suffix).
    const tsFormat = "2006-01-02T15:04:05Z07:00"

    // WriteTable renders records as an aligned 5-column table to w.
    // Column order (LOCKED): ID, STATUS, CONDITION, CREATED, RESOLVED.
    // Sort order (LOCKED): CreatedAt ASC, ties broken by ID ASC.
    // Empty input produces NO output (LD-11: caller owns stderr hint).
    // Returns any Flush error.
    func WriteTable(w io.Writer, records []store.Record) error {
        if len(records) == 0 {
            return nil
        }
        sorted := make([]store.Record, len(records))
        copy(sorted, records)
        sort.SliceStable(sorted, func(i, j int) bool {
            if !sorted[i].CreatedAt.Equal(sorted[j].CreatedAt) {
                return sorted[i].CreatedAt.Before(sorted[j].CreatedAt)
            }
            return sorted[i].ID < sorted[j].ID
        })

        // minwidth=0, tabwidth=0, padding=2, padchar=' ', flags=0
        // → two-space minimum separator, left-aligned, no ANSI.
        tw := tabwriter.NewWriter(w, 0, 0, 2, ' ', 0)
        fmt.Fprintln(tw, "ID\tSTATUS\tCONDITION\tCREATED\tRESOLVED")
        for _, r := range sorted {
            fmt.Fprintf(tw, "%s\t%s\t%s\t%s\t%s\n",
                r.ID,
                r.Status,
                truncate(r.Condition, conditionMaxWidth),
                r.CreatedAt.UTC().Format(tsFormat),
                formatResolvedAt(r.ResolvedAt),
            )
        }
        return tw.Flush() // Pitfall 8: MUST flush or trailing rows vanish.
    }

    // truncate returns s unchanged if len(s) <= max, else s[:max-3] + "...".
    // The length guard (LD-9 / Pitfall 7) prevents a panic on short strings.
    func truncate(s string, max int) string {
        if len(s) <= max {
            return s
        }
        if max < 3 {
            return s[:max]
        }
        return s[:max-3] + "..."
    }

    // formatResolvedAt returns the RFC3339 UTC timestamp, or "-" for nil.
    // Tabwriter right-pads either length to the column width (LD-10).
    func formatResolvedAt(t *time.Time) string {
        if t == nil {
            return "-"
        }
        return t.UTC().Format(tsFormat)
    }

    //
    // Exit codes (LOCKED — LD-1):
    //
    //	0  N entries printed to stdout (or 0 entries → "no entries" to stderr, still exit 0)
    //	1  any load / render error — stderr: "mcp-chain: <err>\n"
    type ListCmd struct{}

    // Run wires statepath → store → runList. Returns nil on success; exits
    // non-zero via os.Exit when runList signals an error (LD-4: no ExitCoder).
    func (c *ListCmd) Run() error {
        path, err := statepath.Resolve()
        if err != nil {
            fmt.Fprintf(os.Stderr, "mcp-chain: %v\n", err)
            os.Exit(1)
        }
        code := runList(os.Stdout, os.Stderr, path)
        if code != 0 {
            os.Exit(code)
        }
        return nil
    }

    // runList maps (path → exit code) with explicit writers. Pure with
    // respect to env vars (LD-3). Empty-store hint goes to stderr with
    // exit 0 (LD-5: POSIX-idiom; pitfall 6).
    func runList(out, errW io.Writer, path string) int {
        st, err := store.Open(path)
        if err != nil {
            fmt.Fprintf(errW, "mcp-chain: %v\n", err)
            return 1
        }
        records, err := st.List()
        if err != nil {
            fmt.Fprintf(errW, "mcp-chain: %v\n", err)
            return 1
        }
        if len(records) == 0 {
            fmt.Fprintln(errW, "mcp-chain: no entries")
            return 0
        }
        if err := format.WriteTable(out, records); err != nil {
            fmt.Fprintf(errW, "mcp-chain: %v\n", err)
            return 1
        }
        return 0
    }

    type PurgeCmd struct {
        ID       string `arg:"" optional:"" help:"Id to purge (mutually exclusive with --all and --resolved)."`
        All      bool   `help:"Purge all entries." xor:"target"`
        Resolved bool   `help:"Purge only resolved entries." xor:"target"`
    }

    // Run wires statepath → store → runPurge. Returns nil on success; exits
    // non-zero via os.Exit when runPurge signals an error (LD-4).
    func (c *PurgeCmd) Run() error {
        path, err := statepath.Resolve()
        if err != nil {
            fmt.Fprintf(os.Stderr, "mcp-chain: %v\n", err)
            os.Exit(1)
        }
        code := runPurge(os.Stdout, os.Stderr, path, c.ID, c.All, c.Resolved)
        if code != 0 {
            os.Exit(code)
        }
        return nil
    }

    // runPurge maps (path, id, all, resolvedOnly → exit code) with explicit
    // writers. Translates store.ErrPurgeArgRequired / ErrUnknownID into the
    // locked stderr lines. Emits NOTHING to stdout on any branch (LD-1).
    func runPurge(out, errW io.Writer, path string, id string, all, resolvedOnly bool) int {
        _ = out // purge emits nothing to stdout (LD-1 success rows all empty)
        st, err := store.Open(path)
        if err != nil {
            fmt.Fprintf(errW, "mcp-chain: %v\n", err)
            return 1
        }
        _, err = st.Purge(store.PurgeOptions{
            ID:       id,
            All:      all,
            Resolved: resolvedOnly,
        })
        switch {
        case err == nil:
            return 0
        case errors.Is(err, store.ErrPurgeArgRequired):
            // Bare `purge` (no args/flags). Kong accepted it because the
            // positional is optional and neither flag was set. Store is
            // the single source of truth for the "exactly one target"
            // check (LD-6 / pitfall 5).
            fmt.Fprintln(errW, "mcp-chain: purge requires <id>, --all, or --resolved")
            return 1
        case errors.Is(err, store.ErrUnknownID):
            fmt.Fprintf(errW, "mcp-chain: unknown id: %s\n", id)
            return 1
        default:
            fmt.Fprintf(errW, "mcp-chain: %v\n", err)
            return 1
        }
    }

    package cli

    import (
        "errors"
        "fmt"
        "io"
        "os"

        "github.com/anthropics/mcp-chain/internal/statepath"
        "github.com/anthropics/mcp-chain/internal/store"
    )

    // ResolveCmd marks an id resolved from the CLI.
    //
    // Exit codes (LOCKED — LD-1):
    //
    //	0  resolved — stdout empty, stderr empty
    //	1  unknown id, not-owner (without --force), already-resolved, any other error
    type ResolveCmd struct {
        ID    string `arg:"" help:"Id to resolve."`
        Force bool   `help:"Bypass the OwnerToken check (operator escape hatch)."`

        path, err := statepath.Resolve()
        if err != nil {
            fmt.Fprintf(os.Stderr, "mcp-chain: %v\n", err)
            os.Exit(1)
        }
        code := runResolve(os.Stdout, os.Stderr, path, c.ID, c.Force)
        if code != 0 {
            os.Exit(code)
        }
        return nil
    }

    // compares it against the record's stamped token (Phase 5 stamps a
    // non-empty 32-char hex token on every register). Without --force,
    // this always fails for Phase 5 records — pitfall 4 / LD-7. The CLI
    // surfaces the --force hint in the ErrNotOwner branch.
    func runResolve(out, errW io.Writer, path, id string, force bool) int {
        _ = out // resolve emits nothing to stdout (LD-1 success row is empty)
        st, err := store.Open(path)
        if err != nil {
            fmt.Fprintf(errW, "mcp-chain: %v\n", err)
            return 1
        }
        err = st.Resolve(id, "", store.ResolveOptions{Force: force})
        switch {
        case err == nil:
            return 0
        case errors.Is(err, store.ErrUnknownID):
            fmt.Fprintf(errW, "mcp-chain: unknown id: %s\n", id)
            return 1
        case errors.Is(err, store.ErrNotOwner):
            fmt.Fprintln(errW, "mcp-chain: not owner (use --force to override)")
            return 1
        case errors.Is(err, store.ErrAlreadyResolved):
            fmt.Fprintln(errW, "mcp-chain: already resolved")
            return 1
        default:
            fmt.Fprintf(errW, "mcp-chain: %v\n", err)
            return 1
        }
    }

    func TestPurge_CounterNotDecremented(t *testing.T) {
        binPath := buildBinary(t)
        dir := t.TempDir()
        statePath := filepath.Join(dir, "mcp-chain", "state.json")
        require.NoError(t, os.MkdirAll(filepath.Dir(statePath), 0o700))

        st, err := store.Open(statePath)
        require.NoError(t, err)

            require.NoError(t, err)

            Counter uint64 `json:"counter"`
        }

## STRIDE Threat Register

| Threat ID | Category               | Component                                                      | Disposition | Mitigation Plan                                                                                                                                                                                                                                                      |
|-----------|------------------------|----------------------------------------------------------------|-------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| T-07-01   | Tampering              | `<id>` positional → `store.Purge`/`store.Resolve` map lookup   | accept      | Both store methods perform pure `map[string]record` lookups (no shell, no SQL, no path concatenation). Shell metachars, path-traversal segments, empty strings all flow through to the exact-match lookup which returns `ErrUnknownID` for non-matching keys. No injection surface. [07-RESEARCH.md §Security Domain V5] |
| T-07-02   | Information disclosure | `format.WriteTable` stdout columns                             | mitigate    | `WriteTable` renders ONLY the 5 whitelisted columns (`ID`, `Status`, `Condition`, `CreatedAt`, `ResolvedAt`). `OwnerToken` is on `store.Record` but is NEVER referenced by the formatter. `TestWriteTable_*` tests pin the column list by name; a future leak via column addition would need a matching test update — a visible audit trail in code review. |
| T-07-03   | Information disclosure | `runList` / `runPurge` / `runResolve` stderr on generic errors | accept      | `fmt.Fprintf(errW, "mcp-chain: %v\n", err)` surfaces the wrapped `store` error. Store error messages (per `internal/store/errors.go`) NEVER embed `OwnerToken` — sentinels only, optionally wrapped with the file path in corrupt-JSON cases. Path disclosure on a single-user local tool is operator-actionable, not sensitive. |
| T-07-04   | Tampering / DoS        | Log injection via `<condition>` containing control chars       | accept      | `format.WriteTable` writes conditions through `fmt.Fprintf(tw, "%s")` — no format-string interpretation. Terminal escape sequences would render (the table is a human display, not a log line); the 48-char `conditionMaxWidth` cap bounds the blast radius. Acceptable for a single-user local tool. For piped consumption, callers can sanitize. |
| T-07-05   | Elevation of privilege | `resolve --force` bypasses OwnerToken check                    | accept      | Documented operator escape hatch (07-CONTEXT.md §Resolve semantics; LD-7). The bypass exists in `store.ResolveOptions{Force}` since Phase 4; Phase 7 surfaces it via a named CLI flag. Filesystem ACL (parent dir 0700 from Phase 3) restricts use to the invoking user — cross-user elevation is not in the threat model for a single-user local tool. |
| T-07-06   | DoS                    | `list` on a huge state.json                                    | accept      | `store.List()` returns `[]Record`; `format.WriteTable` allocates one row per record. At expected entry counts (≤100s per CLAUDE.md), memory ~tens of KB. No streaming rendering needed for v1. If dogfooding Phase 10 surfaces actual issues, Phase 11+ can add pagination — out of scope here. |
| T-07-07   | Tampering              | TOCTOU between `list` and `purge`                              | mitigate    | `list` acquires `LOCK_SH` (Phase 4); `purge` acquires `LOCK_EX` for the full RMW. Race window between a `list` read and a subsequent `purge` is reduced to the time a user takes to parse output and re-invoke — which is the intended semantics (user sees state, decides, purges). No mitigation needed beyond the existing lock discipline. |
| T-07-08   | Information disclosure | `purge` / `resolve` stderr hint via `--force` affordance       | accept      | The `not owner (use --force to override)` line tells an attacker with read-access to the CLI that a `--force` bypass exists. This information is also visible in `--help` output and source code; obscuring it would be security-by-obscurity theatre and would harm the tool's discoverability (a primary v1 goal). |

No new security controls needed in Phase 7. ASVS V5 (input validation) remains partially covered by `store.{Get,Purge,Resolve}`'s map-lookup semantics — no injection sink is introduced by the CLI layer.
