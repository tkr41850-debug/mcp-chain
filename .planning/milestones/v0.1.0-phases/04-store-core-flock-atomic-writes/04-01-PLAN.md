<resolved_decisions>
The following open questions from RESEARCH.md §"Open Questions" are RESOLVED. Future-you:
do not re-litigate these. They are load-bearing for the code shape below.

1. **Sibling `state.json.lock` on BOTH platforms.** Single `lock.go`, no `lock_unix.go` /
   `lock_windows.go` split. `lockFilePath(statePath) = statePath + ".lock"`. Eliminates the
   POSIX rename-changes-inode latent race; uniform semantics cross-platform.

2. **`withSharedLock` takes `s.mu`.** Plain `sync.Mutex` — same-process serialisation of
   reads. Cheap; avoids surprises when callers mix read+write. `sync.RWMutex` is a future
   optimisation (NOT needed for mcp-chain's workload).

3. **Test write-delay hook via function-pointer injection.** Package-level var
   `saveStateFn = saveState` in `store.go`; test file overrides it (`saveStateFn = ...`)
   when exercising kill-mid-write. Zero production-code cost, zero env-var plumbing.

4. **`crypto/subtle.ConstantTimeCompare` for OwnerToken comparison.** Standard hardening
   against timing attacks on a 32-char hex token. ~5 LOC. Use
   `subtle.ConstantTimeCompare([]byte(caller), []byte(stored)) != 1` to signal mismatch.

5. **Pin `github.com/gofrs/flock v0.12.1`.** NOT v0.13.0 (v0.13 requires Go 1.24; project
   is on 1.23.8). All APIs we need (`New`, `Lock`, `RLock`, `Unlock`, `Path`) exist in
   v0.12.1. `renameio/v2` pinned to v2.0.2. CLAUDE.md will be amended out-of-band at phase
   close-out to reflect the v0.12.1 pin.

**`internal/store/lock.go`** (verbatim from RESEARCH.md §"Code Examples: Lock helpers", with
the `s.mu` serialisation on BOTH exclusive and shared paths per Decision #2):

```go
package store

import (
    "fmt"

    "github.com/gofrs/flock"
)

// lockFilePath returns the flock target path for a given state path.
// We ALWAYS use a sibling .lock file (unix AND windows) — uniform cross-platform
// semantics; avoids the POSIX rename-changes-inode latent race.
func lockFilePath(statePath string) string {
    return statePath + ".lock"
}

func (s *Store) withLockedState(fn func(*state) error) (err error) {
    s.mu.Lock()
    defer s.mu.Unlock()

    fl := flock.New(lockFilePath(s.path))
    if err := fl.Lock(); err != nil {
        return fmt.Errorf("store: acquire exclusive lock on %s: %w", fl.Path(), err)
    }
    defer func() {
        if uerr := fl.Unlock(); uerr != nil && err == nil {
            err = fmt.Errorf("store: release exclusive lock: %w", uerr)
        }
    }()

    st, err := loadState(s.path)
    if err != nil {
        return err
    }
    if err := fn(st); err != nil {
        return err
    }
    return saveStateFn(s.path, st)
}

func (s *Store) withSharedLock(fn func(*state) error) (err error) {
    s.mu.Lock()
    defer s.mu.Unlock()

    fl := flock.New(lockFilePath(s.path))
    if err := fl.RLock(); err != nil {
        return fmt.Errorf("store: acquire shared lock on %s: %w", fl.Path(), err)
    }
    defer func() {
        if uerr := fl.Unlock(); uerr != nil && err == nil {
            err = fmt.Errorf("store: release shared lock: %w", uerr)
        }
    }()

    st, err := loadState(s.path)
    if err != nil {
        return err
    }
    return fn(st)
}
```

package store

import (

// writeStateAtomic writes data to path atomically with mode 0600 (CORE-05).
// IgnoreUmask ensures the final file mode is exactly 0600 regardless of
// the process umask (v2 applies umask by default; v1 did not).
func writeStateAtomic(path string, data []byte) error {
    if err := renameio.WriteFile(path, data, 0o600, renameio.IgnoreUmask()); err != nil {
        return fmt.Errorf("store: atomic write %s: %w", path, err)
    }
    return nil
}

**`internal/store/atomic_windows.go`** (verbatim from RESEARCH.md §"Code Examples: Atomic write — windows"):

```go
//go:build windows

package store

import (
    "fmt"
    "os"
    "path/filepath"
)

// writeStateAtomic writes data to path atomically using a same-directory temp file
// and os.Rename (backed by MoveFileEx + MOVEFILE_REPLACE_EXISTING since Go 1.5).
// Safe under the single-writer-flock-protection invariant.
func writeStateAtomic(path string, data []byte) error {
    dir := filepath.Dir(path)
    tmp, err := os.CreateTemp(dir, ".state-*.tmp")
    if err != nil {
        return fmt.Errorf("store: create temp: %w", err)
    }
    tmpPath := tmp.Name()
    defer os.Remove(tmpPath)

    if _, err := tmp.Write(data); err != nil {
        _ = tmp.Close()
        return fmt.Errorf("store: write temp: %w", err)
    }
    if err := tmp.Sync(); err != nil {
        _ = tmp.Close()
        return fmt.Errorf("store: fsync temp: %w", err)
    }
    if err := tmp.Close(); err != nil {
        return fmt.Errorf("store: close temp: %w", err)
    }
    if err := os.Chmod(tmpPath, 0o600); err != nil {
        return fmt.Errorf("store: chmod temp: %w", err)
    }
    if err := os.Rename(tmpPath, path); err != nil {
        return fmt.Errorf("store: rename %s -> %s: %w", tmpPath, path, err)
    }
    return nil
}
```

    cmd := exec.Command(exe)

        "MCP_CHAIN_TEST_WRITE_DELAY=5s",

    cmd.Stderr = os.Stderr
    require.NoError(t, cmd.Start())

    time.Sleep(1 * time.Second) // let child enter the sleep
    require.NoError(t, cmd.Process.Signal(syscall.SIGKILL))
    _ = cmd.Wait() // exits non-zero on SIGKILL; don't assert

    after, err := os.ReadFile(path)
    require.NoError(t, err)
    var parsed interface{}
    require.NoError(t, json.Unmarshal(after, &parsed), "state.json must be valid JSON after SIGKILL")
    require.Equal(t, seeded, after, "SIGKILL before atomic rename must leave old state intact")
}

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller ↔ store API | Caller passes `ownerToken` (Phase 5 MCP server or Phase 7 CLI); token is the auth primitive for Resolve. Token is generated by caller, validated by store. |

| two mcp-chain processes | Coordinated via `gofrs/flock` on sibling `.lock` file. Same OS user; no cross-user trust scenario (single-user tool per PROJECT.md). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Spoofing | `Resolve(id, ownerToken, ...)` | mitigate | `crypto/subtle.ConstantTimeCompare` on OwnerToken (Decision #4). 128-bit token → 2^128 guesses; timing-constant compare prevents side-channel leak of correct token byte-by-byte. |
| T-04-02 | Tampering | `state.json` on disk | mitigate | File mode 0600 via `renameio.IgnoreUmask()` (Pitfall 3); parent dir 0700 is Phase 3's guarantee. Relies on OS ACLs; Windows best-effort. |
| T-04-03 | Tampering | `state.json.lock` on disk | accept | Lock file contains no sensitive data (size 0 in normal use). Attacker with write to the lock file can only DoS by holding the lock — same local user, no privilege escalation. |
| T-04-04 | Repudiation | `--force` resolve bypass | accept | Operator-initiated recovery. Phase 7 CLI will log `--force` usage to stderr (Phase 7 scope, not Phase 4). Phase 4 just implements the bypass; no logging in core. |
| T-04-05 | Info disclosure | Error messages | mitigate | `ErrNotOwner`, `ErrUnknownID` carry no token bytes. ErrCorruptJSON includes file path (local fs, not secret). No token leaks in any `fmt.Errorf` in this phase. Verify via code review. |
| T-04-06 | Info disclosure | Timing side-channel on token compare | mitigate | `crypto/subtle.ConstantTimeCompare` (see T-04-01). |
| T-04-07 | DoS | One process holds LOCK_EX forever | accept | All lock-holders are mcp-chain itself; single-user trust scope. On process crash, OS releases flock on fd close. No external DoS vector. |
| T-04-08 | DoS | State file grows unbounded | accept | Phase 7's `purge --resolved` handles GC. In v1, users self-manage. No `condition` length cap (Phase 5 MCP server may enforce at tool-input boundary). |
